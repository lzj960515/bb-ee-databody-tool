# 数据体工具视频

使用用户的 `personal-ai-workspace` 自媒体工作台制作本项目视频。此 Skill 负责连接项目与工作台；制作工具、依赖、模板和验收流程以工作台中的 Skill 为准。

## 找到工作台

1. 定位当前任务的 `bb-ee-databody-tool` 仓库。当前目录为父工作区时，进入同名子目录；从本 Skill 定位时，以其真实文件位置找到所属仓库。
2. 优先使用已确认的工作台路径，其次检查工具仓库旁的 `../personal-ai-workspace`。用 Git remote 确认其指向 `lzj960515/personal-ai-workspace`，HTTPS 和 SSH 地址视为同一仓库。目录已有内容时保留现状和未提交工作。
3. 工作台尚未克隆时，使用当前 Git 身份将 `https://github.com/lzj960515/personal-ai-workspace` 克隆到上述相邻目录；已有 SSH 身份时使用 `git@github.com:lzj960515/personal-ai-workspace.git`。目录被其他项目占用时另选相邻空目录。访问失败时报告实际原因和所需访问条件，仓库地址已知。
4. 读取工作台 `AGENTS.md`、`STATUS.md` 和 `.agents/skills/create-explainer-video/SKILL.md`，按其中入口继续制作。执行命令按工作台当前说明查找，并明确传入作品目录。

## 确定本期内容

- 从当前请求和项目实际版本确定演示范围，读取相关源码、README 和发布记录。用户只说“做视频”时，以当前工具的核心操作或本次改动为主题推进，将受众、画幅等可调整选择记入作品 `brief.md`。
- 续做或修改已有作品时，从工作台 `content/README.md`、`STATUS.md` 找到对应作品，读取其 `video/index.md` 与 `delivery.md` 后继续。旧记录用于恢复素材、进度和已知运行问题，当前请求决定本次工作。
- 新作品保存到工作台 `content/<日期>-bb-ee-<主题>/video/`。通过新的主题或版本区分作品，保留旧成片与投稿记录。讲稿、素材、源码、字幕、封面和成片均归该作品目录。

## 制作与交付

- 使用当前工具真实界面展示操作与结果；演示存档写入使用合成存档或专用副本，公开素材去除个人路径和存档信息。
- 按工作台视频 Skill 完成讲稿、分镜、配音、字幕、画面、渲染与验收；沿用其资源和命令。复用历史素材前核对版本，游戏实战结论以实际验证为依据。
- 在作品 `index.md`、`delivery.md` 保存可继续编辑的源文件、成片链接和实际验证结果，并按工作台约定同步内容索引与进度。向用户交付可播放的成片与对应素材。
- “做视频”交付本地作品。当前请求或已有明确授权包含本稿件的 B 站发布时，完成制作后继续投稿，沿用已授权账号并核对当前登录身份；保存标题、简介、标签和平台回执。续作前检查已有投稿记录与平台结果，按本次请求更新或新发。分别报告制作完成、投稿成功和审核状态。
