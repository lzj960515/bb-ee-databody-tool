# 苍翼：混沌效应 · 数据体工具

先选想玩的角色和流派，查看开局配置与成型路线，一次创建两个配套继承数据体。也可以自由选择角色、颜色和两项策略，单独创建数据体。

**[下载 Windows EXE 和便携包](https://github.com/lzj960515/bb-ee-databody-tool/releases/latest)**

双击 `数据体工具.exe` 即可使用，不需要安装 Python。工具直接编辑本地存档，每次保存前自动备份。

## 使用方法

1. 完全退出游戏，等待 Steam 完成本次云同步。
2. 打开工具，明确选择要修改的存档槽。
3. 在“流派工坊”选择本局角色和流派，查看“开局继承”“成型路线”“条件与资料”。开局会配好四项策略和两个不同的继承角色，可通过大弹窗调整策略及品质。
4. 选择数据体颜色：紫色（600 分）或金色（700 分），默认紫色。点击“添加两个数据体并保存”，核对两个角色、四项策略及目标存档。
5. 启动游戏，在同一存档的继承选择界面查看新数据体。

点击“查看已有数据体”可打开大窗口，搜索角色或策略；选中一行可以查看两项策略的完整文字。弹窗支持调整大小。

原来的单体功能在“自由添加”页签：选择数据体角色和两项策略，点击“添加数据体并保存”。两种入口共用备份、校验与恢复流程。

工具会在写入后回读校验。两个配套数据体作为一批操作，只备份、提交一次；任何一项不合法或初始仓库空间不足，整批都不会保存。检测到游戏正在运行，或者存档在载入后发生变化时，也会停止保存。

## 流派工坊

内置 9 条整理好的玩法，并覆盖当前目录全部 **100 项双重策略**的目标路线。支持搜索、按元素筛选，也能点击“组合更多双重目标”选择自己想同时玩的策略，再由工具安排四个继承槽与剩余局内路线。

| 玩法 | 核心方向 |
| --- | --- |
| 雷枪光波 | 冲刺落雷 → 落雷光枪 → 光枪光波，后续补电球落雷 |
| 风暴火环 | 技能风暴 → 风暴火环 → 火环燃烧 |
| 光波传递 | 普攻光波命中后向后传递 |
| 撕裂斩杀 | 技能撕裂、致命撕裂与斩杀风暴 |
| 寒气脉冲 | 寒气爆发分支与冰霜脉冲 |
| 触手黑洞 | 召唤触手生成黑洞，再增强减速 |
| 毒弹催化 | 毒弹留下毒液，中毒毒发掉落毒弹，局内补毒液催化 |
| 影链电桩 | 影标与电桩之间传导伤害 |
| 光枪冰锥 | 光枪插地时在周围生成冰锥 |

“开局激活”按实际继承条件计算。比如雷枪光波方案除了冲刺落雷、落雷光枪和光枪光波，还需要基础光枪策略；红色策略的效果名称不能替代基础前置。修改开局四槽后会重新检查触发位、同层策略与双重触发前置冲突。当前组合无法完成时会给出原因，避免把无效组合直接保存。

“成型路线”先显示需要补齐的目标，再显示后续强化建议；“条件与资料”列出继承激活条件、普通局内获取条件、契约和角色提醒，以及公开攻略链接。满足前置不保证随机奖励立即出现。

两个继承角色必须彼此不同，也不能是本局使用角色。默认载体避开 DLC 角色，仍需你在游戏中拥有对应角色和继承功能。载体选择用于携带策略，不代表传承技能或天赋的强度排名。

枣麻衣页面列出“千刃万红”与“风花雪月”的潜能关系。**融会贯通取消的是技能位策略的触发间隔，并让传承技也触发该策略；它不等于角色技能免 MP 或无限释放。**契约、潜能和角色解锁仍需在游戏中取得。

规划按默认契约规则给出可用方案。全部双重目标覆盖不等于穷举所有角色、契约和特殊激活顺序的实战流派；自选组合也不作最高伤害或最短成型保证。现有推荐由游戏配置与脚本核对，并参考[策略 Wiki](https://bbee.huijiwiki.com/wiki/策略一览)、[策略知识详解](https://www.taptap.cn/moment/756618180247421160)、[实用策略整合](https://www.taptap.cn/moment/790198478629241063)等公开资料。攻略中的强度评价和操作建议与游戏硬规则分别标注。

## 新数据体包含什么

- 当前配置含 17 个角色和 297 项有效策略。
- 附带角色初始属性、默认天赋与初始潜能；继承技能为该角色第一项、一级。
- 数据体颜色由评分决定：可选 **紫色 600 分**、**金色 700 分**，两者均达到保存两项继承策略的门槛。灰白和蓝色所需评分低于该门槛，因此不提供；数据体颜色与策略品质分别选择。
- 所选两项策略同时记入拥有策略和继承策略，保留已有数据体。
- 策略可选择白、蓝、紫、金品质。部分联动策略在游戏中显示红色，其实际保存品质仍为 1–4。
- 策略生效条件、互斥、同类合并以及游戏模式限制仍遵循游戏规则。
- 仓库容量沿用游戏已解锁页数，满仓时请先在游戏中整理。工具同步维护数据体编号、角色最高分及累计数据体分数。

## 备份与恢复

备份位于存档 `Save` 文件夹上一级的 `DataBodyToolBackups` 中。保存完成后，界面会显示备份完整路径。每份 `.bak` 配有同名 `.json`，请一起保留。

恢复时先退出游戏，在工具中选择目标存档，再点击“恢复备份…”并选择对应 `.bak` 文件。工具核对所属存档路径及 SHA-256，并在恢复前备份当前文件。恢复会撤销该备份之后此存档的全部进度。

Steam 若提示云存档冲突，请按修改时间和进度核对，选择包含本次修改的本地存档。

## 运行与构建源码

需要 Windows 和 Python 3.10+。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launch.py
```

测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。

公开仓库不包含游戏提取资源或个人存档。依赖这些本地调查资源及 Node.js 的独立游戏校验测试会明确跳过，其余测试使用合成存档运行。

构建：在 `.venv` 安装 `pyinstaller==6.16.0`，执行 `build.ps1`。输出在 `dist`。

推送 `v*` 版本标签时，GitHub Actions 会先运行公开仓库测试，再构建 Windows EXE，并发布 EXE、便携 ZIP、使用说明与 SHA-256 校验文件。发布说明取自附注标签。

项目公开源码、运行所需策略目录和测试；发布包提供 EXE、使用说明和便携 ZIP。
